# OneFix — 같은 고장, 하나의 신고

> 시설 QR로 처리 현황을 확인하고, 같은 고장 신고를 모아 수리와 예방 점검의 우선순위를 정하는 서비스.

학교·기숙사·회사에서 같은 고장을 여러 사람이 따로 신고하는 문제를 해결한다. 사용자는 기존 신고에 참여하고, 관리자는 **영향 인원·처리 상태·반복 고장 이력**을 한곳에서 확인한다.

**진행 조건:** Codex 워크샵 · 2인 1조 · 맥북 1대에서 역할 구분 없이 함께 진행 · 개발 180분. 현재 저장소는 **구현 전 스펙 문서** 단계다. 실행 가능한 앱·API·예측 모델이 구현됐다는 뜻은 아니다.

## 제품 흐름

```text
시설 QR → 현재 고장 확인 ┬→ 같은 문제에 참여 → 영향 인원 증가
                        └→ 새 신고 → AI 중복 판별 → 기존 고장 병합 / 새 고장

관리자 → 영향 인원 순 처리 목록 → 상태·예상 처리 변경 → 사용자에게 공유
       └→ 예방 점검 → 반복 고장 주의도 + 다음 7일 예상 신고량
```

AI는 **증상 문장으로 중복을 판별하는 일**만 맡는다. 사진은 증빙으로 첨부한다. 추가 예측 기능의 첫 버전은 신고 이력을 집계하는 규칙·통계 방식으로 만들고, 실제 고장 확률이나 고장 시점을 단정하지 않는다.

## 구현 우선순위

| 단계 | 기능 | 완료 기준 |
| --- | --- | --- |
| P0 · 필수 | 시설 QR·상태 조회, 참여, 신고, 문장 AI 병합, 관리자 처리 | 사용자 신고부터 관리자 수정·사용자 재조회까지 연결 |
| P1 · 추가 | 사진 1장, 신고량 예상·반복 고장 주의도 카드 | P0 통합 완료 후 시간 내 구현, 데이터 부족·데모 표시 포함 |
| P2 · 이후 | 사진 AI 병합, 실제 고장 예측 모델, 알림, 인증·다중 조직 | 워크샵 이후 별도 진행 |

예측은 P1의 정식 설계 범위다. 125분까지 P0가 통합된 경우 이어서 구현하며, 늦어지면 P1을 미완료로 남기고 P0 검증을 우선한다.

## 한 맥북에서 진행하는 방식

하나의 작업 폴더와 개발 서버에서 기능 단위로 순서대로 구현한다. 팀원별 역할·파일 소유·별도 개발 브랜치를 나누지 않는다.

첫 15분에 실행 환경과 공통 타입을 준비하고, 각 기능의 데이터·API·화면을 연결한 뒤 다음 기능으로 넘어간다. 두 브라우저 프로필로 사용자와 관리자를 시연한다. 상세 작업 순서·인수 조건은 [실행 계획](docs/delivery.md)을 따른다.

불필요한 QA·테스트 추가·반복 검증은 하지 않는다. 문서 수정은 변경 내용 확인으로 마무리하고, 코드 수정은 해당 기능에 필요한 최소 확인만 수행한다. 전체 테스트·타입 검사·lint·build를 매번 일괄 실행하지 않는다.

## 예측 기능의 모습

```text
예방 점검 · 데모 데이터 기반

프린터 A                 반복 고장 주의도: 높음
최근 30일 신규 고장 3건  ·  현재 미해결 1건
다음 7일 예상 신고: 약 7건
근거: 지난 4주 신고 28건 ÷ 4

최근 반복 이력이 있어 예방 점검을 권장합니다.
고장 확률이 아닌 이력 기반 참고 지표입니다.
```

신고량은 같은 사용자의 같은 시설·같은 날짜 신고를 한 번만 세며, 참여 버튼 클릭 수와 구분한다. 숫자·주의도는 임의 생성하지 않고 명세의 계산 결과를 표시한다. 데이터가 부족하면 예상 수치 대신 `데이터 부족`을 표시한다.

## 개발 시작 순서

1. 제품·API 명세와 작업 순서를 함께 확인한다.
2. Next.js + TypeScript + Tailwind CSS 프로젝트와 SQLite를 초기화하고 버전·lockfile을 고정한다.
3. 공통 타입·시드·환경 변수 예시를 추가한다.
4. 조회 → 참여·신고 → AI 병합 → 관리자 → P1 순으로 각 기능의 API와 화면을 연결한다.
5. [완료 조건](docs/delivery.md)의 핵심 흐름을 한 번 확인하고 3분 데모를 준비한다.

로컬 워크샵 시연을 목표로 한다. 앱 초기화와 실행 명령의 계약은 [개발 환경 문서](docs/architecture.md)에 있으며, 현재 저장소에서는 아직 실행할 수 없다.
